## Architecture and module boundaries

One Next.js deployable owns server-rendered UI, JSON API, application services, and an in-process durable document job worker. Modules are: access/masters; projects/contracts; shipments/routes; evidence/documents/outbound; supplier invoices/money/statements; expenses/claims; profit/closure; audit/recovery. A single PostgreSQL transaction protects cross-record invariants. Object metadata/hashes live in PostgreSQL; immutable bytes live in versioned, retention-locked object storage.

No tables, routes, navigation, jobs, or placeholders are planned for deferred features. Stable IDs on Party, Project, MoneyMovement, EvidenceObject, Approval, and AuditEvent are sufficient future extension points.

## Delivery increments

## Operational and quality gates

- WCAG 2.2 AA; Arabic RTL/English LTR parity; exact ORB MD3 visual rules in UI contract.
- Exact decimal arithmetic; optimistic concurrency; idempotent effectful commands; no hard delete of business/evidence/audit records.
- p95 interactive reads <=500 ms and mutations <=800 ms at 50 sessions; document request accepted <=2 seconds and rendered <=30 seconds.
- TLS 1.2+, encrypted database/object/backups, least privilege, MFA for Owner/Admin, secret redaction, zero unaccepted Critical vulnerabilities.
- RPO <=15 minutes, RTO <=4 hours; pre-beta isolated restore proves rows, versions, hashes, allocations, audit chain, and object links.
